- **评审内容**: 每个功能点是否补充场景描述（谁、在什么情况下、为什么需要）？

- **引用依据**: 场景描述支撑功能必要性，是 PRD 必选内容；P1/P2 可延后但须有明确义务声明。
- **修改后复核**: 2026-09-09 已在 v0.3 §5.2 增加覆盖映射与补齐义务，复核通过 ✓
